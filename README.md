# emereese-website

Source for [emereese.com](https://emereese.com), the website of Emereese LLC (data and AI consulting by Kris Kormu).

A single static page served by GitHub Pages. No build step: edit `index.html` and push to `main`.

- `index.html`: the site
- `kris.jpg`: headshot
- `og-image.png`: link preview image for LinkedIn, Slack, and other sites
- `404.html`, `robots.txt`, `sitemap.xml`: housekeeping
- `CNAME`: custom domain
